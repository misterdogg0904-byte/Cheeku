RISHIKA — INTERACTIVE 3D MAGICAL BIRTHDAY WEBSITE

PREVIEW
- Extract this ZIP and double-click index.html to preview in Chrome.
- The opening screen has a 3D envelope. Tap "Open your birthday letter" to enter.
- The site includes a twinkling star canvas, a rotating 3D-style glowing orb, glassy cards, a memory gallery, and an interactive birthday wish.

YOUR PHOTOS ARE ALREADY INCLUDED!
- I added all 14 images from your uploaded ZIP to the assets folder and connected them to the gallery.
- Keep the assets folder alongside index.html when uploading/deploying.

ADD MUSIC (OPTIONAL)
1. Add a song you have permission to use as assets/song.mp3.
2. In index.html, find:
   // document.getElementById('bgMusic').src='assets/song.mp3';
3. Remove the two leading slashes (//), save, and refresh.
4. Music plays only after the visitor taps the music button (browser autoplay rules).

DEPLOY USING GITHUB PAGES
This project is published from the root of the Cheeku repository:
https://github.com/misterdogg0904-byte/Cheeku

In the repository, open Settings -> Pages. Under Build and deployment,
choose "Deploy from a branch", select branch "main" and folder "/ (root)",
then Save. GitHub Pages will publish the site at:
https://misterdogg0904-byte.github.io/Cheeku/

MOBILE CHECK
- Open the published link on your phone before sending it.
- No build command is needed; this is a static website.
- Google Fonts are used for typography; the design still has fallback fonts if offline.
